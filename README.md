# AI Script & Prefab Packer

> **English:** Lightweight GUI tool for packing source code and parsing Unity YAML serialized data (Prefabs, Scenes, Assets) into structured Markdown for AI context.  
> **日本語:** ソースコードのパッキングおよび Unity YAML データ (Prefab/Scene/Asset) のリレーショナル解析を行い、AI 向けコンテキスト（Markdown）を自動生成する Tkinter GUI ツール。  
> **中文:** 用于打包源代码并解析 Unity YAML 序列化数据（Prefab、Scene、Asset）生成 AI 上下文 Markdown 的极简 GUI 工具。
